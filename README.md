# MST Visualizer – Kruskal vs Prim

Static site (HTML + CSS + JS, no build step, no dependencies).

## Folder layout
mst-visualizer/
├── index.html
├── README.md
├── css/style.css
└── js/app.js

## Deploy on GitHub Pages
1. Create a repo (e.g. `mst-visualizer`) and put these files in the repo ROOT
   (index.html must be at the top level, not inside another folder).
2. Commit and push to the `main` branch.
3. Repo -> Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, folder: / (root) -> Save.
4. Wait ~1 minute. Site: https://<your-username>.github.io/mst-visualizer/
